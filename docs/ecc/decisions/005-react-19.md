# ADR 005 — Frontend framework: React 19 (+ Vite 8 / TS 5.9)

**Context:** Sürükle-bırak grid canvas, canlı önizleme ve streaming AI paneli olan etkileşimli bir SPA gerekiyordu. **Alternatives:** Vue/Svelte (ekip aşinalığı daha az), Next.js (SSR ihtiyacı yok, fazladan karmaşıklık). **Decision:** **React 19** + Vite 8 + TypeScript 5.9, @dnd-kit ile sürükle-bırak. **Reasoning:** geniş ekosistem (@dnd-kit, Monaco React, Router 7), Vite ile hızlı dev/HMR, React 19 eşzamanlı özellikleri ve geliştirilmiş form/transition API'leri editör akışına uygun; SPA yeterli (SEO/SSR gereksinimi yok). **Consequences:** SSR yok — ilk yük client-side; tip güvenliği için TS disiplini şart. State yönetimi ayrı ele alındı (bkz. ADR 002).
