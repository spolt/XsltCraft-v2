# ADR 006 — Storage soyutlaması: IStorageService (Local ↔ S3/MinIO)

**Context:** `.xslt` çıktıları ve görsel asset'ler dev'de yerel diske, prod'da S3-uyumlu nesne deposuna (KVKK gereği TR-bölge MinIO/S3) yazılmalı; iş mantığı hangisinin aktif olduğunu bilmemeli. **Alternatives:** doğrudan dosya sistemi çağrıları (prod'a taşınamaz), DB'ye blob yazma (büyük dosyalar için verimsiz). **Decision:** **`IStorageService` soyutlaması** — `LocalStorageService` (dev), `S3StorageService`/MinIO (prod); DI ile `Storage:Provider` ayarına göre seçilir. **Reasoning:** Application katmanı yalnız interface'i tüketir → sağlayıcı değişimi koda dokunmadan config ile yapılır; `.xslt`/görsel DB'ye yazılmaz, DB yalnız `storagePath` tutar (istisna: küçük `UserXsltTemplate` içeriği DB'de). **Consequences:** her yeni depolama ihtiyacı interface üzerinden geçer; path traversal ve asset sahipliği (IDOR) kontrolleri storage sınırında uygulanır. Bkz. `docs/ecc/context/constraints.md`.
