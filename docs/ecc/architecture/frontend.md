# Architecture — Frontend

> Kod-gerçeği. `frontend/xsltcraft-ui/` — Vite + React 19 SPA. Bağlam: `docs/ecc/context/tech-stack.md`, karar: `docs/ecc/decisions/005-react-19.md`, `002-zustand-state.md`, `004-monaco-editor.md`.

## Stack
React 19 · TypeScript 5.9 · Vite 8 · Zustand · TailwindCSS 4 · @dnd-kit (sürükle-bırak) · React Router 7 · Monaco Editor · lucide-react. SSR yok (SPA).

## Klasör yapısı (`src/`)
- **`store/`** — Zustand store'ları: `authStore`, `editorStore` (V2 grid canvas durumu), `xmlStore` (yüklü XML + ağaç), `themeDraftStore` (Tema Kullan ↔ Geliştirici Modu bellek içi taslağı; yaşam döngüsü `ThemeDraftScope` layout route'unda; anahtar `draftKey.theme(id)` / `draftKey.doc(draftId)`), `documentHandoffStore` (Kolay düzenle aktarımı, aşağıda), `aiStore` (flag + panel), `toastStore`.
- **`services/`** — API katmanı (Axios). `apiService` (base client + interceptors; Bearer + otomatik refresh — önizleme/doğrulama ve AI "Uygula"/"Refactor" doğrulaması dahil tüm çağrılar bunun üzerinden, ham `fetch` yalnız NDJSON akışında), alan servisleri: `templateService`, `previewService`, `xsltErrors` (önizleme/doğrulama hata adaptörü, aşağıda), `ublTrService`, `xpathService`, `assetService`, `snippetService`, `userXsltService`, `profileService`, `adminService`, `adminUserService`, `aiAssistantService` (**NDJSON streaming + AbortController**).
- **`components/`** — `editor/` (V2 canvas), `xslt-editor/` (dev mode), `ai/`, `layout/`, `ui/`, route guard'ları.
- **`pages/`** — route seviyesi.

## Sayfalar / routing
Korumalı (`PrivateRoute`): `DashboardPage`, `EditorPage` (V2 grid tasarımcı), `XsltEditorPage` + `DevModePage` (Monaco ham XSLT), `TemplatesPage`/`DraftsPage`/`MyXsltTemplatesPage`, `ProfilePage`, `ThemeUsePage`, `UploadEasyEditPage` (`/easy-edit/:draftId`, `/easy-edit/template/:templateId`). (`Playground` ve `api/templateApi` 2.0.0'da kaldırıldı.) Admin (`AdminRoute`): `admin/{AdminThemesPage, AdminAiPage, AdminSnippetsPage, AdminUsersPage}`. Auth: `auth/{LoginPage, RegisterPage}` (`AuthLayout`). Diğer: `AboutPage`.

## V2 grid canvas editörü (`components/editor/`)
Ürünün kalbi. `Canvas` (A4, serbest X/Y mm yerleşim) → `GridBlockItem`/`BlockCard` (`ResizeHandles` ile px-perfect resize, klavye nudge 1/5mm, undo/redo, Ctrl+D), `BlockPalette` (blok kütüphanesi), `PropertyPanel` (seçili blok + XPath binding), `XmlTreeExplorer` (XML ağacından node→binding), `EditorPreviewPanel` (canlı önizleme, zoom). Sürükle-bırak `@dnd-kit`.

## Dev mode / XSLT editör (`components/xslt-editor/`)
Monaco tabanlı: `XsltEditorToolbar`, `ProblemsPanel` (XML/XSLT/UBL-TR hataları sekmeli), `XPathConsolePanel` (interaktif XPath), `SnippetManagerDialog` (Ctrl+Space autocomplete), `ShareTemplateDialog`/`SaveTemplateDialog`, `ShortcutsDialog`, `XsltEditorPreview` (zoom başlığı). Önizleme `<iframe>`'i yalnız `ScaledPreviewFrame` içinde render edilir; sandbox/başlık/tıkla→satır betiği `previewFrame.ts`'te tek kaynaktır (**postMessage origin + source kontrolü** zorunlu, sandbox çağırandan genişletilemez).

**Tam ekran editör** (`XsltEditorPage`; `hooks/useEditorMaximize`, Ctrl+Shift+F): editör bölmesi yalnız sınıf değişimiyle panel grubunu kaplayan katmana dönüşür — Monaco remount **olmaz**, sağ panel örtülür ama mount kalır (AI sohbeti korunur). Önizleme o sırada `FloatingPreviewWindow`'da (kodun üzerinde yüzen, sürüklenebilir/boyutlandırılabilir mini pencere; `hooks/useFloatingPanel` + `utils/floatingRect`) gösterilir. **Değişmez:** sayfada aynı anda en fazla bir önizleme iframe'i bulunur (yazdırma onu hedefler). Tercih `localStorage['xsltcraft-mini-preview']`.

## XSLT hata adaptörü (`services/xsltErrors.ts`, 2.0.0)
Önizleme/doğrulama hatalarının tek dönüştürücüsü `toXsltError(err)` → `{message, line, column, kind, retryAfterSeconds, isOperational}`. Backend gövdesi `{error, line, column, kind, code, engine}`; `kind` = backend `XsltFailureKind` + hız sınırlayıcının `RateLimited`'i. Operasyonel türler (`Busy`, `UserBusy`, `EngineUnavailable`, `EngineInternal`, `RateLimited`) satır işaretlemez, Türkçe sabit mesaj + `Retry-After` gösterir; `EngineUnavailable` + `code: WorkerDisabled` backend mesajını gösterir. Tüketenler: `previewService`, `xsltEditorStore`, `XsltEditorPage`, `DevModePage`, `EditorPreviewPanel`, `AiApplyDialog`, `AiRefactorDialog`. Önizleme uçları `[Authorize]`dır (anonim → 401). Başarı yanıtındaki `warnings` (yer tutucuya düşen bloklar) henüz UI'da gösterilmiyor.

## Hazır tema logo/imza konumları (`components/theme-assets/`, `components/admin/`)
`ThemeUsePage` + `DevModePage` ortak paneli: `ImagePanel` (yükleme, **Konum** listesi, boyut, hizalama), `BankInfoPanel`, `imageState.ts`. Görselin temaya eklenmesi **sunucuda** (`themeComposeService.composeTheme` → `POST /api/preview/compose`) — önizleme ve indirme aynı koddan geçer; istemcide XSLT'ye betik yazılmaz. Tema Kullan'da `ThemeSlotPreview`: iframe (sandbox `PREVIEW_SANDBOX`, başlık `PREVIEW_IFRAME_TITLE`; genişletilmez) + üst katmanda @dnd-kit bırakma hedefleri. Yuva kutuları `useSlotRects` ile iframe `contentDocument`'ten ölçülür; düzenleme stili `html.xc-edit` sınıfıyla açılır (`@media screen` — yazdırmada görünmez). Sürüklerken iframe `pointer-events:none`. Temadaki görselin yeri (`existing-*` yuvaları) bir `<img>`'dir: kullanıcı görseli onun yerini alır (`isThemeImageSlot`/`usesThemeBox` — boyuta dokunulmadıkça temanın kutusu); düzenleme stili img yuvalarının yerleşimini değiştirmez, gizlenen tema görselini soluk gösterir. Admin izin verdiyse (`slot.removable`) panelde "Temadaki görseli kaldır" (`hiddenThemeImages` → compose `hideThemeImages`). Admin: `ThemeUploadDecisionDialog` (yüklemede 409 → önceden gömülü blok kaldır/koru + temadaki görsellerin rolü), `ThemeSlotReport` (analiz raporu).

## Kolay düzenle — yüklenen XSLT (`components/easy-edit/`, ADR 009)
Ana ekranda (`XsltWorkspace` "XSLT dosyanla çalış", `FileDropZone`, `EditChoiceCards`, `hooks/useUploadAnalysis`) yüklenen XSLT istemcide parse edilir, Pro ve üstüyse (`isProOrAbove`) `POST /api/easy-edit/analyze`'a gider; kartlar **Kolay düzenle** | **XSLT Editör** seçimini sunar (Pro değilse kilitli kart, çağrı yok). XML isteğe bağlıdır; yoksa örnek XML eklenir.
- **Rotalar:** `/easy-edit/:draftId` (aktarım gerekir; yoksa Dashboard'a yönlendirme + toast) ve `/easy-edit/template/:templateId` (şablon sunucudan yüklenip analiz edilir, soru sorulmaz). İkisi de `EasyEditScope` altında `UploadEasyEditPage` → `EasyEditWorkspace`.
- **`EasyEditScope`:** aktarımı tüketir, taslağı `draftKey.doc(draftId)` ile bağlar, düzenleme kilidini (`hooks/useEditingLock`) yönetir.
- **Kaynak bağdaştırıcısı** (`components/theme-use/easyEditSource.ts`, `EasyEditSource`): `EasyEditWorkspace` Tema Kullan ile ortaktır; kaynak farkı bağdaştırıcıdadır — tema (`useThemeEasyEditSource`: `themeId` ya da düzenlenmiş metin) ve doc (`useDocEasyEditSource`: analizin işaretli `xslt`'si + `staticImages` + `conditionalSlots`). Tema akışının davranışı değişmedi.
- **`documentHandoffStore`** (kalıcı değil): `stage(draftId, payload)` / `consume(draftId)` tek seferlik aktarım; analiz önbelleği metin (+ roller) SHA-256 özetiyle (`analysisKey`). `analyzeCached` önce önbelleğe bakar, değişmeyen metin yeniden analiz edilmez (`unavailable` önbelleğe yazılmaz).
- **Görseller:** dosyadan tespit edilen logo/imza `origin:'extracted'` olarak hazır yüklü gelir; bırakınca doğrudan taşınır; taşıma, boyut ve kaldırma compose'a `staticImages` olarak gider; serbest görsel `FreeImagesPanel` (≤ 1), dosyadaki IBAN tablosu `docBank` + `BankInfoPanel` ile düzenlenir; yeni yüklenen görsel mevcut asset akışını kullanır. Tek soru adımı `ImageRolesDialog` (rol seçenekleri `theme-assets/roleOptions`, admin diyaloğuyla ortak); yalnız önerilen rol ya da önceki ekleme varsa açılır.
- **Editör ↔ Kolay düzenle:** Kolay → Editör, güncel compose çıktısını `location.state.pendingXsltContent` (+ `pendingXsltName`, `templateId`, `dirty`) ile `XsltEditorPage`'e verir (`editorHandoff.readEditorHandoff`); Editör → Kolay metni stage edip analiz eder (`useEasyEditModeSwitch`, `stageEasyEditFromEditor`). Mod anahtarı `DocumentBar`/`EditorModeBar`; editörde kapatılabilir öneri bandı (`EasyEditHintBand`, tercih `uiPrefsStore.easyEditHintDismissed`). Geçişte aynı şablonun kilidi bırakılmaz: `hooks/lockHandoff` (`markLockHandoff` → yeni sayfa kilidi alınca temizlenir, kısa TTL).
- **Son mod:** kayıt `lastEditMode` yazar; `utils/workRoutes.xsltOpenPath(id, lastEditMode, isPro)` `easyEdit` + Pro ise `/easy-edit/template/:id`, değilse `/xslt-editor/:id` (`useRecentWork`, `MyXsltTemplatesPage`).
- **`services/easyEditGuards`:** analiz yanıtındaki veri yalnız güvenli biçimde kullanılır — `safeImageSrc` (yalnız `data:image/*;base64` ve yalnız `<img src>`), `isValidSlotId`/`filterSlotIds` (yuva kimliği deseni). Analiz `xslt`'si yalnız metin olarak kullanılır; önizleme her zaman sunucu render'ı + sandbox'lı iframe. Kullanıcıya gösterilen metinler React metin düğümüdür.

## AI paneli (`components/ai/`)
`AiAssistantPanel` (UBL-TR Türkçe asistan; NDJSON akışı, `AbortController` ile iptal, toast), `AiRefactorDialog` (XSLT seçimi → dönüşüm → diff → onayla). **Kullanıcı onayı olmadan otomatik insert yok**; insert öncesi `/api/preview/validate-xslt`. UI'da `aiEnabled` (`useAiStore(s => s.enabled === true)`) kontrolü unutulmamalı.

## Konvansiyonlar
- State: özellik-bazlı küçük Zustand store'ları; selector ile hedefli abonelik (gereksiz re-render yok).
- API: `apiService` üzerinden; streaming uçları (`aiAssistantService`) `BodyWriter`/fetch reader pattern'i ile.
- Pre-commit hook: `console.log` ve hardcoded `localhost` URL (frontend) commit'lenmez — config'i `apiService`/env'de tut.
